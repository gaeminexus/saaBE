# G43 — ParticipeCesanteG43

> ⚠️ Si se modifica la lógica de este reporte, actualizar este archivo.

**Tabla destino:** `RPR.CG43`
**Servicio:** `GeneracionG43ServiceImpl.java`

## Lógica
1. Obtener identificaciones del G42 del mes actual → conjunto "activos".
2. Obtener identificaciones del G42 del mes anterior:
   - Si existe EJRC anterior → usar `RPR.CG42` de ese EJRC.
   - Si NO existe EJRC anterior → usar `RPR.HM42` (HistoricoG42).
3. `cesantes = universo_anterior - activos_actuales`
4. Por cada cesante: buscar su `Entidad` por `numeroIdentificacion` y calcular los campos de liquidación desde `CRD.APRT`.
5. Insertar en `CG43`.
6. Si no hay cesantes → retornar 0, EJRD OK.

## Campos calculados (desde CRD.APRT)

| Campo | Lógica |
|---|---|
| `numeroImposicionesPersonales` | COUNT de aportes con `tipoAporte.codigo IN (9, 11)` y `valor > 0` de la entidad |
| `numeroImposicionesPatronales` | COUNT de aportes con `tipoAporte.codigo IN (13, 14)` y `valor > 0` de la entidad |
| `fechaTerminoRelacionLaboral` | Último día del mes **anterior** al mes del EJRC |
| `fechaLiquidacion` | Último día del mes actual del EJRC |
| `saldoCuentaIndividual` | `ABS(SUM de aportes con valor < 0, tipoAporte.estado = 1, fechaTransaccion dentro del mes de ejecución)` de la entidad |
| `valoresCompensados` | Siempre `0` |
| `valoresPagados` | Mismo valor que `saldoCuentaIndividual` |

## Métodos nuevos en AporteService / AporteDaoService

| Método | Descripción |
|---|---|
| `selectCountImposicionesPersonalesPorEntidad(Long)` | COUNT aportes > 0 tipos 9, 11 |
| `selectCountImposicionesPatronalesPorEntidad(Long)` | COUNT aportes > 0 tipos 13, 14 |
| `selectMinNegativoPorTipoAporteG43(Long)` | MIN valor negativo por tipo IN (9,11,23), retorna `Object[]{Long tipoAporte, Double minValor}` |
